## 🌟 Core Features & Architecture

### 1. 🏰 VOXEL-GYM & VOXEL-ARENA (3D Multi-Agent Open World Benchmark)
- **High-Performance 60 FPS WebGL Engine (Three.js)**: Continuous 3D solid voxel heightfield featuring mountain peaks, quartz summits, rolling green hills, blooming flowers, and flying 3D birds.
- **4 Autonomous Frontier AI Avatars**:
  - 🟢 **Claude 3.7 Sonnet**: *The Emerald Cyber-Spire* (Neo-Tokyo skyscraper with glowing cantilever decks).
  - 🟣 **GPT-4.5 (Frontier)**: *The Quantum Monolith Citadel* (Concentric stepped pyramid with floating crystal core).
  - 🟡 **DeepSeek R1**: *The Obsidian Fortress* (4 corner bastions with castellated battlements).
  - 🔵 **Gemini 3 Pro**: *The Solar Hyper-Gate* (360° circular Stargate torus with ruby energy nexus).
- **4-Way Quad-Split Benchmark Feeds**: Simultaneous live 3D tracking cameras monitoring each AI model's real-time Chain-of-Thought (CoT) reasoning stream, laser tool calls, and spatial structural scores.
- **First-Person Minecraft Mode & Orbit Drone Mode**: Walk across the landscape, fly/jump with Space, and inspect megastructures up close.
- **Dynamic Solar Lighting Cycle**: Day, Sunset, and Cyberpunk Night with glowing emissive neon blocks.

### 2. 🎮 The 5-Genre GameDev Matrix
5 fully playable HTML5 Canvas games built, synthesized, and evaluated by AI models:
- 🟡 **Cyber-Pac Protocol**: Tile-grid collision physics & 4-Ghost Euclidean Flanking AI.
- 🚀 **Neural Asteroids: Vector Space Combat**: Newtonian 2D vector physics, inertia, momentum drift, laser cannons, particle explosions.
- 🏎️ **Cyber-Racer: 2.5D Vector Drift**: Pseudo-3D raycast perspective, dynamic road curves, traffic AI, nitro boosts.
- ⚡ **Quantum Defense: Swarm Automata**: Creep wave pathfinding, placeable Pulse/Cryo/Plasma turrets, gold economy.
- 🗡️ **Matrix Roguelike: Procedural Crypt**: Procedural BSP dungeon carving, fog of war, turn-based monster AI, combat rolls.

### 3. ⚔️ Model Battle Royale Arena
- Live split-screen head-to-head competition pitting frontier models against each other on the exact same challenge (Quantum Gate Synthesis, Async Memory Leak Mitigation, Zero-Day ROP Patching).

### 4. 🧠 MCTS Reasoning Tree Inspector
- Interactive Monte Carlo Tree Search (MCTS) visualization showing exploration nodes, rollout values $Q(s, a)$, visit counts $N(s, a)$, and pruned dead branches.

### 5. 🔬 Frontier Evaluation Gyms
- **Quantum-Gym**: 12-Qubit Entanglement & CNOT Gate Depth Optimization (Qiskit).
- **Recursive-Gym**: Self-Improving Meta-Agent Auto-Grader Optimization.
- **Sec-Gym**: Zero-Day Heap Corruption & ROP Chain Exploit Defense.
- **SWE-Gym**: Distributed Async Race Conditions & Memory Leak Patching.

## 🚀 Quickstart & Installation

### Prerequisites
- Node.js (v18.0 or higher)
- npm / yarn / pnpm

### Setup
```bash
# 1. Clone the repository
git clone https://github.com/MagnusDrake/automechanica-ai-engine.git
cd automechanica-ai-engine

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Open in browser
# http://localhost:3000
```

### Production Build
```bash
npm run build
```
